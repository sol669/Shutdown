1. Откройте https://github.com/sol669/Shutdown
2. Нажмите Add file → Upload files.
3. Распакуйте этот архив на компьютере.
4. Перетащите в окно GitHub ВСЁ содержимое папки Shutdown-WinUI3-Source:
   - папку .github
   - папку src
   - README.md
   - LICENSE
   - .gitignore
5. Внизу нажмите Commit changes.
6. Откройте вкладку Actions.
7. Если GitHub попросит разрешить Actions, подтвердите.
8. Дождитесь зелёной галочки у Build portable.
9. Откройте запуск и скачайте artifact Shutdown-Portable-win-x64.

Важно: загружать нужно содержимое папки, а не саму внешнюю папку целиком.
